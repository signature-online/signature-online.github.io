# Подпись онлайн / Online Signature

Бесплатный инструмент: нарисуйте подпись мышью, пальцем или стилусом и скачайте PNG без фона или векторный PDF.
Всё работает в браузере — подпись никуда не отправляется.

## Структура

- `src/template.html` — страница (HTML/CSS/JS приложения) с плейсхолдерами `{{key}}`
- `src/i18n/*.json` — тексты на каждом языке (UI, SEO, FAQ)
- `src/site.json` — адрес сайта, код GoatCounter, коды верификации поисковиков
- `src/static/` — favicon, OG-картинки, файлы верификации
- `build.mjs` — сборка в `dist/` (без зависимостей): `node build.mjs`

Деплой — GitHub Actions → GitHub Pages при каждом push в `main`.
